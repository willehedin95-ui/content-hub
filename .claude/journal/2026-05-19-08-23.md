## Major learnings from THIS session

### För Claude (framtida sessions)
1. **Time-bounded autonomous work betyder TIME-BOUND** - om user säger "kör 8 timmar" så ska arbetet faktiskt vara 8 timmar. Inte stoppa när jag tycker det är "klart". William var (rätteligen) upprörd när jag stoppade efter 50 min av en 8h-plan.
2. **Read SOURCE CODE först, inte CLAUDE.md only** - jag gjorde gap-analys baserat på CLAUDE.md utan att verifiera mot actual .swift-files. Resulterade i 70% wrong "actionables" som var redan implementerade. Always read code first.
3. **CronCreate session-only != durable** - även med `durable: true`-flag stod den som "session-only". scheduled-tasks-MCP är persistent men kräver user-interaction-approval-mode.
4. **När estimat är fel, säg det** - mitt original-estimat 200h reducerades till 47h efter code-läsning. Var transparent med kortrigering snarare än släta över.
