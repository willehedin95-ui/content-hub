## Major learnings

### För Claude (framtida sessions)
1. **Memory's "Hydro13 UX-research 2026-05-19 är opålitlig"-regel hade jag glömt** — citerade ALTERNATIVE-AVATARS-research mid-session, William påpekade att jag hittade på "Anna är glömsk/skeptisk". Hard rule re-anchored: använd bara `renew-brand.md` + `hydro13-product.md` + `hydro13-economics.md` som auktoritativ source för avatar/copy. ALTERNATIVE-AVATARS är hallucination.
2. **iOS launch storyboard är finicky** — `INFOPLIST_KEY_UILaunchScreen_*` keys är inte tillförlitliga. Bäst pattern: storyboard-config för iOS-level + SwiftUI SplashView som backup.
3. **`body` som property name krockar med View.body** — `struct DoseStepRow { let body: String }` ger "invalid redeclaration of 'body'". Använd annat namn (t.ex. `stepBody`).
4. **`@Previewable @State` kan inte ha `return`-statement** — "cannot use explicit 'return' statement in the body of result builder 'ViewBuilder'". Ta bort return.
5. **iOS Color asset i sRGB hex (0xEB...) renderar peach i simulator** — använd `UIColor(red:green:blue:alpha:)` direkt i SwiftUI istället för Color från asset.
6. **Files i pbxproj refereras med path relative to group** — om jag wirar in en fil med `path = "X.swift"` i ContentView's group, måste filen ligga på `Hydro13/X.swift`, inte `Hydro13/Views/X.swift`. Annars build failar med "input file cannot be found".
