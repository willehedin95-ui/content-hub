## Decisions made

- **Use Python f-strings for HTML templating in offer_html_body.py** - simple but requires `{{` `}}` escapes in CSS. Trade-off accepted vs introducing template engine.
- **Inline all CSS in offer_html_body.py** instead of loading from external Supabase URL - 158KB total (HTML + CSS) but fully self-contained, no extra HTTP request, easier to iterate.
- **Don't add age question as a disqualify-gate** - 1+ år bucket continues normal flow. Maries FAQ explicitly says "samma metoder fungerar upp till 2 år".
- **Escape-link for "all clear" options** - removes inconsistent dual-pick risk on multi-select while keeping data capture for analytics.
- **CSS `:has()` selector avoided** - replaced with universal padding-bottom on quiz-content (160px) since `:has()` had inconsistent matching in iframe context.
